# Fonts Backup Repository

This repository is used to store and back up personal font collections, including programming and terminal fonts.

## Contents

The repository may contain:

- Nerd Fonts
- Monospace fonts
- Programming fonts
- Terminal fonts
- Custom font collections
- Archived font versions

## Included Fonts

Examples of fonts that may be stored here:

- FiraCode Nerd Font
- JetBrains Mono Nerd Font
- Cascadia Code
- Hack Nerd Font
- Meslo Nerd Font
- Ubuntu Mono Nerd Font

## Purpose

The goal of this repository is to:

- Maintain a centralized font backup
- Simplify font synchronization across machines
- Preserve specific font versions
- Quickly restore development environments

```text
fonts/
├── NerdFonts/
```
